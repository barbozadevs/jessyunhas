JESSY UNHAS — GITHUB PAGES

1. Envie todos os arquivos desta pasta para a raiz do repositório GitHub.
2. Vá em Settings > Pages.
3. Selecione Deploy from a branch > main > / (root).
4. Salve e aguarde a publicação.
